# 03. 웹 사용 매뉴얼 (Threads Auto Pro)

`http://127.0.0.1:5001` 화면은 상단 헤더의 탭 3개로 구성됩니다:
**⚙️ 설정 & 계정 / 📁 데이터 입력 / 📊 대시보드**. 우측 상단에는 자동화 실행 상태(Idle / 작동 중) 표시등이 있습니다.

---

## 탭 1: ⚙️ 설정 & 계정

### AI & System (왼쪽 카드)

| 항목 | 설명 |
|------|------|
| **Headless Mode** | 체크하면 게시할 때 크롬 창을 화면에 띄우지 않고 백그라운드에서 실행. 화면의 안내대로 **체크 해제 권장** — 헤드리스 모드는 봇 감지에 더 잘 걸리고 화면 구조가 달라져 실패율이 높음 |
| **발행 후 대기 시간(초)** | 설정 화면에는 있지만 **현재 코드에서는 실제로 사용되지 않는 값** (uploader가 파라미터로 받기만 하고 안 씀 — 문서 06 참고). 게시 후에는 고정 5초 대기 |
| **OpenAI API Key** | AI 리라이팅에서 `GPT`(gpt-4o-mini 모델) 선택 시 사용 |
| **Gemini API Key** | AI 리라이팅에서 `Gemini`(gemini-2.5-flash → 2.0-flash → flash-latest 순으로 시도) 선택 시 사용 |
| **System Prompt** | AI가 본문을 다시 쓸 때 따를 지침 (말투, 길이, 이모지 사용 등) |

설정은 입력값이 바뀔 때마다 자동 저장되고, `config.json`에 평문으로 기록됩니다 (API 키 포함 — 이 파일을 남에게 보내면 안 됨).

### Accounts (오른쪽 카드)

- **+ 추가**: 계정 "닉네임"을 등록. 이 닉네임은 실제 Threads 아이디가 아니라 **이 프로그램 안에서 세션을 구분하는 관리용 이름**입니다 (한글 가능).
- **로그인**: 크롬 창이 뜨면 → 인스타그램 로그인 페이지가 열림 → 직접 로그인 → 프로그램이 자동으로 threads.net으로 이동해 로그인 성공을 감지 → 세션(쿠키)을 `sessions/`에 저장. 성공하면 상태가 "로그인 완료"로 바뀌고, 실제 로그인된 핸들(@아이디)이 닉네임 옆에 표시됩니다.
- **✏️ 닉네임 변경**: 이름을 바꿔도 세션 파일과 예약 대기열의 계정명이 자동으로 함께 변경됨.
- **🗑️ 삭제**: 계정과 세션 파일 삭제.

> 닉네임에서 영문/숫자/밑줄 이외 문자는 세션 파일명 생성 시 제거됩니다. 예: "내계정1" → `1.json`. **한글로만 된 닉네임 두 개(예: "본계정", "부계정")는 같은 파일명으로 충돌**할 수 있으니 닉네임에 영문이나 숫자를 섞는 것이 안전합니다 (문서 06 참고).

## 탭 2: 📁 데이터 입력

게시물을 행 단위로 입력하는 표입니다. 열 의미:

| 열 | 필수 | 설명 |
|----|:---:|------|
| **내용 (Content)** | ✅ | 게시할 본문. 이 칸이 비어 있는 행은 저장되지 않음 |
| **댓글 (Comment)** | | 본문 게시 직후 같은 스레드에 달 첫 댓글. 쿠팡 파트너스 링크 등을 넣는 용도. URL이 있으면 링크 미리보기 카드를 자동으로 제거함 |
| **파일경로 (File)** | | 첨부할 이미지/영상의 **절대경로**. 쉼표로 여러 개 지정 가능. **폴더 경로**를 넣으면 그 폴더 안의 미디어 파일들을 이름순으로 전부 첨부 (지원: png/jpg/jpeg/webp/gif/heic/mp4/mov/m4v) |
| **태그 (Tag)** | | 해시태그. 쉼표/공백 구분, `#`은 자동으로 붙여줌. 본문 맨 아래에 합쳐짐 |
| **주제 (Topic)** | | Threads의 주제 기능 대신 **해시태그로 변환되어 본문 끝에 추가**됨 |
| **시간 (Time)** | ✅ | `HH:MM` 형식 (예: `09:00`). **오늘 이 시각이 되면** 게시됨 |
| **언어** | | KO/EN/JA 선택. 저장만 되고 현재 게시 로직에서는 쓰이지 않음 |
| **AI** | | OFF / GPT / Gemini. GPT나 Gemini를 선택하면 게시 직전에 본문을 AI가 리라이팅 |
| **계정 (ID)** | ✅ | 어느 계정으로 올릴지 선택 (설정 탭에서 등록·로그인한 계정) |

### 상단 도구 모음

- **🕒 시작 시간 + 간격(분) + 일괄 적용**: 첫 행부터 지정 간격으로 시간을 자동 채움 (예: 09:00 시작, 20분 간격 → 09:00, 09:20, 09:40 …)
- **🕒 시간 정렬 / 👤 1계정 우선 / 👥 다계정 순서**: 행 정렬 도구. "다계정 순서"는 계정 A→B→A→B 식으로 교차 배치
- **🤖 전체 AI 변환**: AI가 GPT/Gemini로 설정된 모든 행의 본문을 한 번에 리라이팅. 변환 후에는 게시 시 이중 변환을 막으려고 해당 행의 AI 설정이 자동으로 OFF가 됨 (행별 🔄 리롤 버튼도 동일)
- **🔄 초기화**: 표 전체 비우기
- **📥 템플릿**: 열 형식이 맞는 CSV 템플릿 다운로드
- **📂 불러오기**: CSV/엑셀 파일 업로드. 열 이름에 "내용/댓글/파일/태그/주제/시간/언어/ai/계정" 등의 키워드가 있으면 자동 매핑
- **예약 실행 ✈️**: 표 내용을 `queue.json`에 저장하고 스케줄러를 시작 → 대시보드 탭으로 이동

### CSV 파일 형식 예시

```csv
내용 (Content) *,댓글 (Comment),파일경로 (File),태그 (Tag),주제 (Topic),시간 (Time),언어,AI (GPT/Gemini/Free),계정 (ID) *
본문 내용입니다,첫번째 댓글내용,/absolute/path/to/image.jpg,#태그1,인테리어,09:00,KO,OFF,my_account_id
```

- 인코딩은 UTF-8(BOM 포함 권장, 엑셀에서 저장하면 자동).
- 내용 칸이 비고 댓글만 있는 행은 **바로 위 행의 댓글에 줄바꿈으로 이어붙는 연속 행**으로 처리됩니다.

## 탭 3: 📊 대시보드

- **▶️ 자동화 시작 / ■ 중지**: 예약 스케줄러 on/off. "예약 실행 ✈️"을 눌렀다면 이미 시작된 상태.
- **실시간 예약 작업 대기열**: 각 행의 상태 표시 — `대기(Pending)` → `진행중(Running)` → `성공(Success)` / `실패(Fail)`
- **SysTek Logs**: 서버 로그 실시간 스트리밍(SSE). 게시 과정의 각 단계, 네트워크 응답, 실패 원인이 여기에 찍힘. **문제가 생기면 가장 먼저 볼 곳.**

## 예약이 실제로 실행되는 조건 (중요)

1. Flask 서버(`app.py`)가 **켜져 있어야** 하고,
2. 자동화가 **시작 상태**여야 하며 (상단 표시등이 초록),
3. 행 상태가 `Pending`이고,
4. **현재 시각(HH:MM)이 행의 시간과 정확히 일치**하는 순간에 스케줄러가 감지해야 함.

지나간 시간의 예약은 실행되지 않고 `Pending`으로 남습니다. 같은 계정의 작업이 아직 진행 중이면 그 분(minute) 안에서만 재시도하고, **그 분이 지나면 영영 실행되지 않습니다** (알려진 한계 — 문서 06 참고). 한 번 `Success`/`Fail`이 된 행은 다시 실행되지 않으며, 재실행하려면 데이터 입력 탭에서 다시 "예약 실행"으로 저장해 `Pending`으로 되돌려야 합니다.
