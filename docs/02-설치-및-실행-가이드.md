# 02. 설치 및 실행 가이드

macOS 기준입니다 (실행 스크립트 `run.command`가 macOS 전용). 다른 OS에서도 파이썬 명령을 직접 치면 동작합니다.

## 사전 준비물

- Python 3.9 이상
- 인터넷 연결 (Playwright 브라우저 다운로드 및 Threads 접속용)
- Threads(= Instagram) 계정

## 1. 가상환경 만들기

실행 스크립트(`run.command`, `run_gui.command`)는 프로젝트 폴더 안에 `venv/` 가상환경이 있다고 가정합니다. **저장소에는 venv가 포함되어 있지 않으므로 처음 받았다면 직접 만들어야 합니다.**

```bash
cd /Users/dongwoon/dev/toy/threads-automation
python3 -m venv venv
source venv/bin/activate
```

## 2. 의존성 설치

> ⚠️ **주의:** `requirements.txt`에는 `customtkinter`, `playwright`, `pandas`, `openpyxl` 4개만 적혀 있는데, 실제 코드는 **`flask`, `openai`, `google-generativeai`도 import** 합니다.
> `requirements.txt`만 설치하면 `app.py` 실행 시 `ModuleNotFoundError`로 즉시 죽습니다.
> ("어떤 컴퓨터에서는 되고 어떤 컴퓨터에서는 안 되는" 원인 중 하나 — 원래 개발 PC의 venv에는 수동 설치돼 있었을 것)

전체 설치 명령:

```bash
pip install -r requirements.txt
pip install flask openai google-generativeai
```

## 3. Playwright 브라우저(Chromium) 설치

Playwright는 패키지 설치와 별도로 **브라우저 바이너리를 한 번 내려받아야** 합니다. 이 단계를 빼먹으면 로그인/게시 버튼을 눌러도 "Executable doesn't exist" 류의 에러가 납니다.

```bash
playwright install chromium
```

## 4. 실행

### 웹 버전 (권장)

```bash
./run.command        # 또는: python app.py
```

- Flask 서버가 `http://127.0.0.1:5001`에서 뜨고, `run.command`는 3초 뒤 기본 브라우저로 그 주소를 자동으로 엽니다.
- 서버는 터미널을 닫거나 `Ctrl+C`를 누르면 종료됩니다. **서버가 꺼져 있으면 예약도 실행되지 않습니다.**
- Finder에서 `run.command`를 더블클릭해도 됩니다 (최초 1회 `chmod +x run.command` 필요할 수 있음).

### 데스크톱 GUI 버전 (구버전)

```bash
./run_gui.command    # 또는: python main.py
```

> ⚠️ 현재 `uploader.py`의 버그(pandas 미임포트 등) 때문에 GUI 버전은 **엑셀 업로드와 로그인 세션 열기가 동작하지 않습니다.** 문서 06의 버그 목록을 고쳐야 사용 가능합니다.

## 5. 첫 실행 후 해야 할 일

1. 웹 화면의 **⚙️ 설정 & 계정** 탭에서 계정 닉네임(임의의 관리용 이름)을 추가한다.
2. 계정 옆 **"로그인"** 버튼을 누르면 크롬 창이 뜬다 → **인스타그램 계정으로 직접 로그인**한다 → 프로그램이 자동으로 Threads로 넘어가 로그인 성공을 감지하고 세션을 `sessions/<계정명>.json`에 저장한 뒤 창을 닫아도 된다.
3. (선택) AI 리라이팅을 쓰려면 OpenAI 또는 Gemini API 키와 System Prompt를 입력하고 저장한다.
4. **📁 데이터 입력** 탭에서 게시물을 입력하거나 CSV/엑셀을 불러온 뒤 **"예약 실행 ✈️"** 을 누른다.

자세한 사용법은 [03-웹-사용-매뉴얼.md](03-웹-사용-매뉴얼.md) 참고.

## 실행하면 생기는 파일들 (git에는 없음)

| 파일/폴더 | 용도 |
|-----------|------|
| `config.json` | 설정(헤드리스 여부, API 키, 시스템 프롬프트, 계정 목록) |
| `queue.json` | 예약 대기열 (각 행의 내용/시간/상태) |
| `sessions/<계정>.json` | 저장된 로그인 쿠키 (⚠️ 유출 시 계정 탈취 가능한 민감 파일) |
| `sessions/profile_<계정>/` | 로그인용 크롬 프로필 폴더 |
| `sessions/error_*.png` | 게시 실패 시 자동 저장되는 에러 스크린샷 |

모두 `.gitignore`에 등록되어 있어 git에 올라가지 않습니다.

## 자주 겪는 설치/실행 문제

| 증상 | 원인과 해결 |
|------|-------------|
| `ModuleNotFoundError: No module named 'flask'` (또는 openai, google...) | 2번 단계의 추가 패키지 미설치. `pip install flask openai google-generativeai` |
| `Executable doesn't exist ... chromium` | `playwright install chromium` 안 함 |
| `run.command` 더블클릭 시 "source: no such file or directory: venv/bin/activate" | venv를 안 만들었음. 1번 단계 수행 |
| 5001 포트 사용 중 에러 | 이미 서버가 떠 있음. 기존 프로세스 종료 후 재실행 |
| 로그인은 됐는데 게시가 "세션 만료" 실패 | 쿠키 만료. 해당 계정 "로그인"을 다시 수행 |
