## 30초 요약

- **무엇?** Meta의 SNS **Threads(스레드)에 글·사진·영상을 자동으로 예약 게시**해 주는 로컬 프로그램. 쿠팡 파트너스 링크 등을 첫 댓글로 다는 마케팅 자동화 용도로 만들어짐.
- **어떻게?** 공식 API가 아니라 **Playwright로 크롬 브라우저를 조종**해서 사람이 클릭하는 것처럼 게시함 (봇 감지를 피하기 위해 마우스를 S자 곡선으로 움직이는 등의 트릭 포함).
- **화면 2가지:**
  1. **웹 버전 (메인)** — `app.py` 실행 → 브라우저에서 `http://127.0.0.1:5001` 접속. 여러 계정, 시간 예약, AI 본문 변환 지원.
  2. **데스크톱 GUI 버전 (구버전)** — `main.py` 실행. customtkinter 창. (한동안 코드 버그로 실행이 불가능했으나 2026-07-14에 수정됨)
- **왜 됐다 안됐다 하나?** Threads 화면 구조(선택자)에 의존하는 브라우저 자동화라는 태생적 한계 + 코드 안에 확인된 버그 여러 개가 겹쳐 있었음. 자세한 내용은 [문서 06](06-문제-분석-됐다-안됐다-원인.md) 참고 — **확인된 코드 버그들은 2026-07-14에 수정 완료** (각 항목에 ✅ 표시).
